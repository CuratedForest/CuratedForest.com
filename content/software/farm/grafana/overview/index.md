Grafana is the visualization layer that turns raw time-series data
into actionable insight. Curated Forest uses Grafana dashboards to
monitor real-time conditions, spot anomalies, and track long-term
trends across the grow zones. A single glance at the overview panel
shows which zones are thriving and which need attention — color-coded
by deviation from target ranges. Alerting rules push notifications
when critical thresholds are crossed, so I can respond before a small
drift becomes a lost crop.

Dashboards are stored as JSON and version-controlled alongside the
rest of the Curated Forest configuration, making it easy to share
proven monitoring setups or roll back a change that didn't work out.
